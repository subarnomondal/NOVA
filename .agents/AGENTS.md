## Git Updates
- Before making any git updates (like `git add` or `git commit`), ALWAYS check the `.gitignore` file as a reference to confirm it is correctly configured and that no unwanted files (like temporary data, API keys, etc.) will be committed. This is a strict system instruction.

## UI Generation
- When using Stitch (or any UI generation tools), ALWAYS create highly detailed prompts.
- Before generating UI, visualize the entire project scope and ensure it fits into the broader architecture.
- Ensure that all generated UI is fully functional and interactive. DO NOT create dummy, placeholder, or non-working UI.
